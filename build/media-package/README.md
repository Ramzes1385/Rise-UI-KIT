# Отдельный пакет плеера

Заготовка отдельного репозитория `@ramzes1385/rise-media-player` (порция 4.13 v2). Сам репозиторий и публикацию делает владелец.

Сейчас плеер живёт в ките и подключается отдельным входом `@ramzes1385/rise-ui-kit/media`. Код кита он берёт только из публичных входов пакета — это проверяет `build/tests/packageBoundaries.spec.ts` («границы плеера»): каждое имя, которое папка плеера импортирует из кита, должен экспортировать корень, `/components`, `/composables`, `/utils` или `/icons`. Поэтому перенос механический.

## Как получить содержимое репозитория

```sh
node build/media-package/extract.mjs ../rise-media-player
cd ../rise-media-player
npm install
npm run build
```

`extract.mjs` кладёт в пустую папку:

- шаблон проекта из `template/`: `package.json` (кит и Vue в peerDependencies), `vite.config.ts` (lib-сборка, `vue` и кит — внешние), `tsconfig.json`, `tsconfig.build.json` (типы в `dist`), README пакета;
- плеер без тестов и stories: `index.ts`, `model/`, `types/`, `ui/`, `styles/` в `src/`; импорты `@components/*`, `@composables/*`, `@utils/*`, `@icons/*` и `@/locales` переписаны на `@ramzes1385/rise-ui-kit/components`, `/composables`, `/utils`, `/icons` и корень. Импорт другого внутреннего модуля кита останавливает скрипт с ошибкой;
- SCSS-помощники кита (`_functions.scss`, `_mixins.scss`, `_variables.scss`) в `src/styles/kit/` без токенов.

Проверено в порции 4.13: извлечённый пакет собирается против собранного кита (`dist/index.js` ≈113 КБ, `dist/media.css` ≈21 КБ), `vue-tsc` строит типы без ошибок, а тестовая страница с плеером из этого пакета и китом из `dist` играет запись, показывает русские подписи и открывает меню «Настройки».

## Что решить перед переносом

- **Тесты и stories.** Сейчас они в ките и опираются на его тестовую инфраструктуру (Vitest, Storybook, помощники stories). В новом репозитории им нужна своя настройка — или они остаются в ките до выхода пакета.
- **Строки интерфейса.** Раздел `player` остаётся в словаре кита: плеер читает его через публичный `useLocale()`. Если словарь плеера переедет в пакет, в ките раздел можно оставить для совместимости.
- **Иконки.** Иконки плеера (`cast`, `subtitles`, `skip-next` и другие) лежат в спрайте кита: пакету нужна версия кита, в которой они есть.
- **Версия кита.** В шаблоне — `^2.0.0`: плеер опирается на публичный API 2.0.
