# Ожидаемые визуальные изменения (visual-baseline)

Редизайн переписал стили всех 51 компонента на токенах `--rise-*` ([DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)) и все stories ([STORIES_GUIDE.md](./STORIES_GUIDE.md)). Поэтому меняются все снимки: другой вид компонентов, другой набор stories и их id (`ui-basex--*` → `<раздел>-basex--*`), а тёмная тема снимается у каждой story через `&globals=theme:dark`, а не отдельной story `DarkTheme`. Baseline намеренно не обновлены автоматически: сначала сверьте снимки с этим документом. Чтобы принять изменения, запустите `npm run test:visual:update` локально (только на Linux: имя снимка от платформы не зависит, а рендер шрифтов зависит) или поставьте PR метку `visual:update-baselines` — CI перегенерирует снимки на Linux и закоммитит их в ветку. Старые снимки удалены: 496 файлов с прежними именами без темы (`base-x--<story>-visual-chromium.png`, `base-x-<story>-visual-chromium.png`) в `<X>.visual.spec.ts-snapshots/` и `__tests__/<X>.visual.spec.ts-snapshots/`. Новые — `base-<компонент>-<story>-<light|dark>-visual-chromium.png` в `tests/visual-snapshots/src/components/<X>/__tests__/<X>.visual.spec.ts-snapshots/`: 51 spec, 255 stories × 2 темы = 510 файлов.

Какие stories снимаются, задаёт массив `STORIES` в `__tests__/<X>.visual.spec.ts`. Оверлеи и открытые панели (Modal, Slideover, Dropdown, Popover, Tooltip, Tour, Notification, DatePicker, Select, Search, ColorPicker, Range, Image) снимаются целой страницей. Ниже для каждого компонента — что было и что стало.

## Общее для всех компонентов

- **Токены.** Цвета — только семантические токены `--rise-*`. HEX, `rgba()` и `--color-*` из стилей компонентов убраны.
- **Нейтральная палитра — по-прежнему zinc, но роли цветов разведены.**
  - Текст — zinc-700, вторичный текст — zinc-500, заголовки и значения — zinc-900.
  - Рамки поверхностей — zinc-200. Рамки полей, чекбоксов и outline-кнопок — zinc-300 (раньше везде zinc-200).
- **Основной цвет.**
  - Светлая тема: orange-500 `#f97316` с белым текстом (контраст 2.8:1) → orange-700 `#c2410c` (5.18:1).
  - Тёмная тема: orange-400 с белым текстом (2.3:1) → с тёмным текстом zinc-950.
  - Остальные роли в светлой теме тоже темнее (было 500): success — green-700, info — blue-600, warning — amber-700, error — red-600.
- **Радиусы.**
  - Контролы, пункты меню и поповеры: 8px → md 6px.
  - Карточки, окна, алерты и тосты: 8–12px → lg 8px.
  - Бейджи и тултипы — sm 4px; пилюли, аватары и переключатели — full.
- **Высота контролов.** Было ≈39px (отступ 10px и `line-height: normal`), стало 32px при `sizeScale` 100: рамка 1 + отступ 5 + строка 20 + отступ 5 + рамка 1. Кнопка, поле, селект, пин-код и триггеры даты и цвета теперь одной высоты.
- **Кегль задаётся парой «размер/интерлиньяж».**
  - Было 13–15px с `line-height: normal` (≈17px). Стало: 14/20 — основной текст, 12/16 — подписи и счётчики, 16/24 — заголовки. Строки текста стали выше примерно на 3px.
  - Начертание контролов и подписей: было 600 (у подписей через BaseText фактически 400), стало medium 500.
- **Фокус.**
  - Кнопки и ссылки: двойной `box-shadow` → кольцо 2px `--rise-focus-ring` с отступом 2px, только по `:focus-visible`. У края контейнера с `overflow: hidden` кольцо рисуется внутри элемента.
  - Поля: рамка accent и кольцо 3px → рамка и кольцо 1px primary.
- **Тёмная тема** включается токенами на тех же компонентах. Фон страницы — zinc-900 (в старых stories `DarkTheme` фоном была обёртка zinc-950), приподнятые поверхности — zinc-800, рамки — zinc-800/700.
- **Тени.**
  - Поверхности — без тени или с `shadow-sm`; плавающие панели — `lg`; модальные окна и выезжающие панели — `xl`.
  - У полей в варианте `shadow`: `lg`/`xl` → `xs`. Кнопки по умолчанию больше без тени.
- **Состояния.**
  - Отключённый элемент: opacity 0.4–0.6 → 0.5 с курсором `not-allowed`.
  - Hover и active меняют фон, рамку и тень; `filter: brightness()`, `scale()` и `translateY()` убраны.
  - Длительности анимаций — токены 150/200/300 мс. Декоративные анимации работают только при `motion-safe`.
- **Подписи в составных компонентах** — `span` и `p` вместо BaseText. Inline-стиль `font-weight: 400` больше не перебивает начертание.
- **Окружение снимков.**
  - Время зафиксировано: 15 мая 2025, 10:30.
  - `openStory` ждёт завершения play и загрузки шрифтов, поэтому на снимке — конечное состояние.
  - Изображения — локальные SVG data URI.

## Element

### BaseAlert
- `default`: мягкий фон и рамка роли → заливка `--rise-{роль}` с текстом `--rise-on-*`.
- Варианты: `soft` — мягкий фон без рамки; `outline` — рамка `-border` без фона; `ghost` — только текст; `shadow`: цветной с хардкод-тенью → нейтральная карточка (bg, рамка, `shadow-sm`).
- Отступы: 16 → 12/16, иконка–текст 12 → 10px, радиус lg. Однострочный алерт — 46px.
- Заголовок: semibold → 14/20 medium. Описание: ≈12.6px с `opacity .9` → 14/20 цветом алерта.
- «Закрыть»: прямоугольная кнопка с иконкой 12px и `opacity .6` → квадратная ghost 24px с иконкой 16px; в `default` кольцо фокуса цвета текста.

### BaseAnimation
- На снимке — конечное состояние после play.
- `list`: `ul > div > li` → элементы стали прямыми потомками `tag` и анимируются по отдельности.
- Длительности: литералы 0.3–0.5 с → токены: появление 200 мс (bounce, rotate, flip и zoom — 300 мс), исчезновение 150 мс.
- `slide`: сдвиг 20 → 16px. `scale`: 0.9 с «пружиной» → 0.95 ease-out. `flip` — с перспективой 600px. `collapse` плавно анимирует высоту.

### BaseAvatar
- Размер при `sizeScale` 100: 40 → 32px (пресеты 75–125 — от 24 до 40px).
- Инициалы: 600 muted → 16/24 medium `--rise-text-toned`; у `soft` — `primary-text`.
- Варианты:
  - `default`: surface-muted с рамкой → `bg-elevated` без рамки;
  - `soft` — `primary-soft`; `outline` — фон bg и рамка accented; `shadow` — рамка и `shadow-sm`;
  - квадратная форма: радиус 8 → 6px.
- Изображение: рамка, подложка и радиус 12px от BaseImage → голый `<img>`.
- Статус «в сети»: 12px с рамкой 2px (всего 16px) → точка 10px с кольцом 2px `--rise-bg`. `scale` при наведении убран.

### BaseBadge
- Варианты: `default`: серый фон и `--color-text` → заливка primary с текстом `on-primary`; `soft` — `primary-soft` с `primary-text`; `outline` — bg и рамка accented; `shadow` — рамка и `shadow-sm`.
- Размер: 14px semibold, отступ 4/10, «пилюля» → высота 20px, 12/16 medium, отступ 2/8 с рамкой, радиус sm 4px.
- Длинный `label` обрезается многоточием. Бейдж выровнен по середине строки, иконка в слоте отстоит на 4px.
- `scale(1.05/0.95)`, `brightness` и двойное кольцо фокуса убраны.

### BaseButton
- `default`: `#f97316` с `shadow-sm` → `#c2410c` без тени (в тёмной теме — orange-400 с тёмным текстом). `soft`: почти чёрный текст → `primary-text`.
- Варианты:
  - `outline`: прозрачный фон и рамка zinc-200 → фон bg и рамка accented;
  - `ghost`: текст muted → `--rise-text`;
  - `shadow`: белый фон с `shadow-lg`/`xl` → фон bg, рамка, `shadow-sm`; при наведении `bg-muted` и `shadow-md`.
- Размер:
  - было: отступ 10/20, 14px semibold, ≈39px, радиус 8px;
  - стало: отступ 5/10 из токенов, 14/20 medium, 32px, радиус md 6px.
- Состояния: hover и active — `brightness(1.1/0.9)` и смена тени → меняется только фон. Фокус: двойной `box-shadow` → кольцо 2px с отступом.
- Длинный текст обрезается многоточием. Спиннер: 18 → 16px по центру; ширина кнопки при загрузке сохраняется.

### BaseCard
- Отступы секций: 24/48 → 16/20. Текст тела: наследуемые 16px → 14/20.
- Заголовок: 18px → 16/24 semibold highlighted. Подзаголовок: muted с `opacity .7` → 14/20 muted; между ними 4px.
- Подвал: фон bg-muted → без фона, с линией сверху. У карточки из одной шапки больше нет пустого тела высотой 48px.
- Варианты: `outline`: рамка 2px без фона → рамка accented 1px; `soft`: оранжевый `primary-soft` → `bg-elevated` 50%; `shadow`: `lg` (при наведении `xl`) → `sm`.
- `isHoverable`: `translateY(-4px)` и оранжевая рамка → рамка accented и `shadow-sm`. С `height` без `scroll` показывается ровно 3 строки с многоточием, высота включает рамку.

### BaseChip
- Индикатор: 20px, 11px bold, рамка 2px bg-muted → 18px, 12/16 medium с табличными цифрами, кольцо 2px `--rise-bg`.
- `default`: красный `--color-error` → primary. Красный счётчик теперь задаётся через `color` (story CustomColor).
- Варианты: `outline`: красные рамка и текст → bg и рамка accented; `ghost`: прозрачный с рамкой → bg без рамки; `shadow`: красный → нейтральный с `shadow-sm`.
- Проп `color` раньше перекрашивал содержимое слота, теперь красит только индикатор.

### BaseIcon
- Сами иконки не изменились: 20px при `sizeScale` 100, цвет `currentColor`.
- `gallery`: 24 иконки из захардкоженного списка → все иконки спрайта: 94, включая новые `dots-horizontal`, `star-filled` и `upload`; с переключателем темы — ещё `sun` и `moon`; с плеером и записью (этап 4) — ещё 12: `volume`, `volume-off`, `fullscreen`, `fullscreen-exit`, `settings`, `theater`, `theater-exit`, `subtitles`, `skip-previous`, `skip-next`, `cast`, `stop`. Всего 108. Иконки идут по алфавиту имён, поэтому новые встают в середину сетки: ячейки после них сдвигаются, а сетка становится длиннее.
- Корень: `<div>` → `<span>`; раскладка та же.

### BaseImage
- Радиус: inline `calc(12px × масштаб)` → md 6px из стилей. Рамка 1px и серый фон убраны; фон виден только при `fit="contain"`.
- Плейсхолдер — `bg-elevated` с шиммером. Ошибка: эмодзи 🖼️ и текст 11px → иконка `image` 20px dimmed и подпись 12/16 toned.
- Просмотр (`gallery`):
  - подложка: `rgba(0,0,0,.85)` → black 88%;
  - кнопки: 36px на «пилюле» → круглые ghost 32px с белыми иконками, разделитель перед «Закрыть».
- Стрелки галереи: 44px black 40% → 40px black 60% с обводкой. Активная миниатюра: рамка accent → кольцо 2px primary; остальные миниатюры — с прозрачностью 0.6.
- Изображение в просмотре: до 90% × 85% экрана → поля 72/64px; панель и миниатюры его больше не перекрывают.

### BaseLoader
- Индикатор: 36 → 32px, цвет `--rise-primary`. Спиннер: «червяк» → дуга в ¼ окружности на треке `bg-accented`.

- Оверлей: `rgba(0,0,0,.3)` + `blur(2px)` → `--rise-bg` 80% без размытия.

### BaseProgress
- Линия: трек 10px surface-muted → 8px `bg-accented`, радиус full.
- Подпись линии: тёмный тултип над заливкой → текст 14/20 muted над полосой; вместе с подписью компонент высотой 36px.
- Круг: 100 → 64px. Подпись: 18px bold → 14/20 semibold highlighted.
- Неопределённый режим: круг — пустое кольцо с «0%» → вращающаяся дуга без подписи; линия — бегущий отрезок 40%.
- `striped`: белые полосы 15% по 20px → `on-primary` 20% по 16px. `glow`: серое свечение → свечение цветом заливки (60%).

### BaseSeparator
- Линия: фон → рамка `--rise-border`. Пунктир: градиент 8/6px → `border-style: dashed`.
- Подпись: 13px 500, отступы 10/20 → 12/16 medium muted, отступы 0/12. Высота разделителя с подписью: 36 → 16px.
- Вертикальный: `min-height` 24 → 20px; тянется на всю высоту ряда, у подписи отступы 12px.

### BaseSkeleton
- Фон `bg-elevated`, цвет прежний. `rect`: радиус 8px без масштаба → md 6px с масштабом.
- Шиммер: белая полоса 10% (в тёмной теме 5%) → `bg-accented` 80%, только при `motion-safe`.

### BaseText
- Интерлиньяж: `normal` (≈17px) → 20px при кегле 14px. Строка выше примерно на 3px, поэтому меняется высота всех компонентов с текстом на BaseText.

- Цвет `--rise-text` и шрифт `--rise-font-sans` по значению совпадают с прежними.

## Chat

### BaseChat
- Оболочка: у `flat` без рамки, у `modern` — радиус xl и `shadow-lg` → одинаковая карточка во всех вариантах; варианты меняют только сообщения.
- Шапка — 56px. Аватар: 40 → 32px. Кнопки поиска и информации: 24px со `scale` → ghost 32px.
- Сообщения:
  - пузыри: радиус 16px, «хвост» и тень → радиус lg без «хвоста» и тени;
  - свои: accent с белым текстом → `primary-soft`;
  - время и статус: внутри пузыря → под ним.
- Поле ввода — textarea высотой 32px, растёт до 140px. Кнопка отправки: круглая → квадратная 32px. «Другие действия» — иконка `dots-horizontal`.
- Пустая лента — BaseEmpty «Сообщений пока нет». Панель «Информация»: своя 320px → BaseSlideover 336px с вкладками-«пилюлями».

## Editor

### BaseEditor
- Коробка: радиус 8 → 6px. Фокус: кольцо 3px rgba → рамка и кольцо 1px primary. Readonly: `opacity .7` → фон `bg-muted`.
- Тулбар: фон surface-muted → прозрачный; кнопки 27×27 с иконкой 20px → 28×28 с иконкой 16px; включённый формат: заливка accent → `primary-soft`; разделитель групп — линия 1×20px.
- Область текста: 15px/1.7, минимум 232px → 14/20, высота 160–600px.
- Типографика: em-шкала заголовков → 20/18/16/14 semibold. Цитата: 4px accent с фоном → линия 3px без фона. Блок кода: «окно» `● ● ●` → `bg-muted` с рамкой.
- Варианты: `outline` 2px → 1px; `soft`: `primary-soft` → `bg-elevated` 50%; `shadow`: `lg` → `xs`. `color` красит только область текста.
