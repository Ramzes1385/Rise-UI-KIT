# Ожидаемые визуальные изменения (visual-baseline)

Редизайн переписал стили всех 51 компонента на токенах `--rise-*` ([DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)) и все stories ([STORIES_GUIDE.md](./STORIES_GUIDE.md)). Поэтому меняются все снимки: другой вид компонентов, другой набор stories и их id (`ui-basex--*` → `<раздел>-basex--*`), а тёмная тема снимается у каждой story через `&globals=theme:dark`, а не отдельной story `DarkTheme`. Baseline намеренно не обновлены автоматически: сначала сверьте снимки с этим документом. Чтобы принять изменения, запустите `npm run test:visual:update` локально (только на Linux: имя снимка от платформы не зависит, а рендер шрифтов зависит) или поставьте PR метку `visual:update-baselines` — CI перегенерирует снимки на Linux и закоммитит их в ветку. Старые снимки удалены: 496 файлов с прежними именами без темы (`base-x--<story>-visual-chromium.png`, `base-x-<story>-visual-chromium.png`) в `<X>.visual.spec.ts-snapshots/` и `__tests__/<X>.visual.spec.ts-snapshots/`. Новые — `base-<компонент>-<story>-<light|dark>-visual-chromium.png` в `tests/visual-snapshots/src/components/<X>/__tests__/<X>.visual.spec.ts-snapshots/`: 51 spec, 255 stories × 2 темы = 510 файлов.

Какие stories снимаются, задаёт массив `STORIES` в `__tests__/<X>.visual.spec.ts`. Оверлеи и открытые панели (Modal, Slideover, Dropdown, Popover, Tooltip, Tour, Notification, DatePicker, Select, Search, ColorPicker, Range, Image) снимаются целой страницей. Ниже для каждого компонента — что было и что стало.

## Общее для всех компонентов

- **Токены.** Цвета — только семантические токены `--rise-*`. HEX, `rgba()` и `--color-*` из стилей компонентов убраны.
- **Нейтральная палитра — по-прежнему zinc, но роли цветов разведены.**
  - Текст — zinc-700, вторичный текст — zinc-500, заголовки и значения — zinc-900.
  - Рамки поверхностей — zinc-200. Рамки полей, чекбоксов и outline-кнопок — zinc-300 (раньше везде zinc-200).
- **Основной цвет.**
  - Светлая тема: orange-500 `#f97316` с белым текстом (контраст 2.8:1) → orange-700 `#c2410c` (5.18:1).
  - Тёмная тема: orange-400 с белым текстом (2.3:1) → с тёмным текстом zinc-950.
  - Остальные роли в светлой теме тоже темнее (было 500): success — green-700, info — blue-600, warning — amber-700, error — red-600.
- **Радиусы.**
  - Контролы, пункты меню и поповеры: 8px → md 6px.
  - Карточки, окна, алерты и тосты: 8–12px → lg 8px.
  - Бейджи и тултипы — sm 4px; пилюли, аватары и переключатели — full.
- **Высота контролов.** Было ≈39px (отступ 10px и `line-height: normal`), стало 32px при `sizeScale` 100: рамка 1 + отступ 5 + строка 20 + отступ 5 + рамка 1. Кнопка, поле, селект, пин-код и триггеры даты и цвета теперь одной высоты.
- **Кегль задаётся парой «размер/интерлиньяж».**
  - Было 13–15px с `line-height: normal` (≈17px). Стало: 14/20 — основной текст, 12/16 — подписи и счётчики, 16/24 — заголовки. Строки текста стали выше примерно на 3px.
  - Начертание контролов и подписей: было 600 (у подписей через BaseText фактически 400), стало medium 500.
- **Фокус.**
  - Кнопки и ссылки: двойной `box-shadow` → кольцо 2px `--rise-focus-ring` с отступом 2px, только по `:focus-visible`. У края контейнера с `overflow: hidden` кольцо рисуется внутри элемента.
  - Поля: рамка accent и кольцо 3px → рамка и кольцо 1px primary.
- **Тёмная тема** включается токенами на тех же компонентах. Фон страницы — zinc-900 (в старых stories `DarkTheme` фоном была обёртка zinc-950), приподнятые поверхности — zinc-800, рамки — zinc-800/700.
- **Тени.**
  - Поверхности — без тени или с `shadow-sm`; плавающие панели — `lg`; модальные окна и выезжающие панели — `xl`.
  - У полей в варианте `shadow`: `lg`/`xl` → `xs`. Кнопки по умолчанию больше без тени.
- **Состояния.**
  - Отключённый элемент: opacity 0.4–0.6 → 0.5 с курсором `not-allowed`.
  - Hover и active меняют фон, рамку и тень; `filter: brightness()`, `scale()` и `translateY()` убраны.
  - Длительности анимаций — токены 150/200/300 мс. Декоративные анимации работают только при `motion-safe`.
- **Подписи в составных компонентах** — `span` и `p` вместо BaseText. Inline-стиль `font-weight: 400` больше не перебивает начертание.
- **Стили без комментариев (порция Д.5).** Из `src/styles` убраны комментарии и неиспользуемые миксины; CSS пакета совпадает с прежним побайтно, кроме `visually-hidden`: устаревшее `clip: rect(0, 0, 0, 0)` заменено на `clip-path: inset(50%)` (28 правил). Элементы остаются невидимыми и доступными скринридеру; на 50 историях 25 компонентов с такими элементами замена `clip` на `clip-path` на той же странице картинку не меняет (три истории с анимацией меняются и без замены), снимки не меняются.
- **Точный «Show code» (серия Ш).** Истории переводятся на общий шаблон для превью и кода (`storySource`, `useStorySetup`); разметка превью не меняется, снимки тоже. Element (Ш.1): 157 из 168 историй попиксельно как раньше, остальные 11 различаются и между двумя прогонами исходной сборки (лоадеры, анимация, счётчики BaseChip). Form (Ш.2): 262 из 276 попиксельно как раньше, 13 различаются и между двумя прогонами исходной сборки, BaseSwitch Keyboard — от прогона к прогону.
- **Окружение снимков.**
  - Время зафиксировано: 15 мая 2025, 10:30.
  - `openStory` ждёт завершения play и загрузки шрифтов, поэтому на снимке — конечное состояние.
  - Изображения — локальные SVG data URI.

## Element

### BaseAlert
- `default`: мягкий фон и рамка роли → заливка `--rise-{роль}` с текстом `--rise-on-*`.
- Варианты: `soft` — мягкий фон без рамки; `outline` — рамка `-border` без фона; `ghost` — только текст; `shadow`: цветной с хардкод-тенью → нейтральная карточка (bg, рамка, `shadow-sm`).
- Отступы: 16 → 12/16, иконка–текст 12 → 10px, радиус lg. Однострочный алерт — 46px.
- Заголовок: semibold → 14/20 medium. Описание: ≈12.6px с `opacity .9` → 14/20 цветом алерта.
- «Закрыть»: прямоугольная кнопка с иконкой 12px и `opacity .6` → квадратная ghost 24px с иконкой 16px; в `default` кольцо фокуса цвета текста.

### BaseAnimation
- На снимке — конечное состояние после play.
- `list`: `ul > div > li` → элементы стали прямыми потомками `tag` и анимируются по отдельности.
- Длительности: литералы 0.3–0.5 с → токены: появление 200 мс (bounce, rotate, flip и zoom — 300 мс), исчезновение 150 мс.
- `slide`: сдвиг 20 → 16px. `scale`: 0.9 с «пружиной» → 0.95 ease-out. `flip` — с перспективой 600px. `collapse` плавно анимирует высоту.

### BaseBadge

### BaseButton

- **BaseSlider с `isAutoplay`** — в левом верхнем углу слайдов круглая кнопка «Остановить/Запустить автопрокрутку» (значок пауза/пуск, подложка `--rise-media-surface`, белый значок), отступ 12px. Затронута история Autoplay (`data-baseslider--autoplay`); в скриншот-тестах её нет.
- **BaseSlider ArrowPositions** — без видимых изменений (у каруселей появились разные имена `label`).
- **Токены `--rise-media-*`** (BaseImage — окно просмотра, BaseSlider — подписи и миниатюры видео) — значения прежние: Default и Fits BaseSlider/BaseImage совпадают с базой попиксельно в обеих темах; Gallery BaseImage отличается на 3×1 px в тёмной теме — та же разница есть между двумя прогонами базы (нестабильна в базе).
- **BaseImage** с `aspectRatio` и `width` вместе — теперь ширина применяется, высота считается из пропорций (раньше ширина игнорировалась). В историях кита такого сочетания нет.
- **BaseImage** с пустым `src` — мерцающая заглушка вместо «Ошибка загрузки» (миниатюра видео без `poster` в BaseSlider).

Эталоны скриншот-тестов, которые это затронет: нет — `*.visual.spec.ts` BaseSlider и BaseImage не включают Autoplay, а остальные снимки совпадают с базой. Эталоны не трогались.

## Задача fu-upload-docs: BaseFileUpload, BaseMenu, шрифт пакета

- **BaseFileUpload** — в зоне под «Выберите файлы» появилась строка «Перетащите файлы сюда» (`emptyText`, текст 12px, цвет `--rise-text-muted`): зона выше на одну строку во всех историях. Разделитель «·» в подсказке зоны и в строке файла стоит в конце фрагмента, а не в начале следующего: при переносе строка больше не начинается с «·» (без переноса вид тот же). Подсказка о форматах — MIME-типы строчными (`image/*`), расширения прописными (`.PDF`).
- **BaseFileUpload** — без `uploader` у выбранного файла нет статуса «Ожидание» и нет прогресса/«Загружено» (раньше у изображений через ~1 с — «Загружено»): строка — имя, расширение и размер. С `uploader` — процент и полоса, «Загружено» или «Ошибка» с текстом ошибки (12px, `--rise-error`) под строкой и кнопкой повтора (ghost, круговая стрелка) рядом с крестиком. Истории Loading (с `uploader`) и новая UploadError.
- **BaseFileUpload** — `allowPreview: false` показывает иконку типа файла вместо миниатюры.
- **BaseMenu** — пункт с `to`/`href` — ссылка (BaseLink ghost): вид пункта тот же (без подчёркивания, цвет текста пункта); новая история Links.
- **Шрифт** — в пакете (`dist/styles.css`) элементы `base-*` получают `--rise-font-sans`: в приложении без своего правила шрифта компоненты больше не показываются системным шрифтом. В Storybook без изменений.
