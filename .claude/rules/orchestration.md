# Служебные папки оркестровки

- `.orchestration/` — правила ролей облачных сессий, очередь задач, переписка с ними; `.rise-transfer/` — обмен кодом и статусы облачных сессий. Обе — только на компьютере владельца, в git не входят (`.git/info/exclude`).
- Не удаляй и не правь их без просьбы владельца: по ним работает оркестратор. Сводка по ним — `/orchestra`, как устроено — `.orchestration/README.md`.
- `.rise-transfer.bundle` в корне репозитория — временный файл переноса, его убирает оркестратор.
