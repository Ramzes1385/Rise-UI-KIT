# Rise UI Kit

Библиотека компонентов для Vue 3: 51 компонент — от кнопки до таблицы, чата и редактора. Визуальный язык в духе Nuxt UI:
нейтральные поверхности, тонкие рамки, единая высота контролов, фокус-кольцо и тёмная тема на тех же токенах.

## Установка

```bash
npm install @ramzes1385/rise-ui-kit
```

```ts
import { createApp } from 'vue'
import { createUiKitPlugin } from '@ramzes1385/rise-ui-kit'
import '@ramzes1385/rise-ui-kit/styles'

createApp(App).use(createUiKitPlugin({ iconSpritePath: '/icons.svg' })).mount('#app')
```

Шрифты Inter и JetBrains Mono подключает приложение — см. README, раздел «Шрифты».

## Как устроен Storybook

| Раздел | Что внутри |
|---|---|
| **Foundations** | Токены: цвета, типографика, радиусы и тени, размеры, темы. С них стоит начать |
| **Element** | Базовые элементы: кнопка, бейдж, карточка, алерт, аватар, иконки, прогресс, лоадер |
| **Form** | Поля и контролы форм: поле ввода, селект, поиск, даты, переключатели, загрузка файлов |
| **Data** | Отображение данных: таблица, дерево, календарь, аккордеон, карусель, пустое состояние |
| **Navigation** | Вкладки, меню, хлебные крошки, пагинация, боковая панель, шаги |
| **Overlay** | Модальное окно, выезжающая панель, поповер, выпадающий список, тултип, уведомления, тур |
| **Chat**, **Editor** | Составные компоненты: чат и редактор текста |

У каждого компонента одинаковая структура stories:

1. **Default** — песочница: все props меняются в панели Controls, v-model работает.
2. **Variants**, **Sizes**, **CustomColor** — внешний вид.
3. **Disabled**, **Loading**, **WithError**, **Empty**… — состояния.
4. Сценарии, характерные для компонента.
5. **Keyboard** — проверка клавиатуры (только в сайдбаре).

Таблица props в Docs сгруппирована по смыслу: содержимое, внешний вид, состояние, поведение, события, слоты.
Тема переключается кнопкой «Тема» на панели инструментов.

## Три правила библиотеки

- **Размер — `sizeScale`.** Одно число в процентах: 100 — контролы высотой 32px, 75/87.5/112.5/125 — размеры xs/sm/lg/xl.
  Кнопка, поле, селект и переключатели одного `sizeScale` одной высоты.
- **Цвет — токены `--rise-*`.** Тема, бренд и скругления меняются переменными, без правок стилей компонентов.
  Точечно перекрасить один компонент можно пропом `color`.
- **Доступность по умолчанию.** Подписи связаны с полями, у кнопок-иконок есть имена, оверлеи держат фокус,
  контраст токенов проходит WCAG AA в обеих темах.

Подробнее — в `docs/design/DESIGN_SYSTEM.md` (дизайн-система) и `docs/design/STORIES_GUIDE.md` (как писать stories) репозитория.
